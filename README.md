# OpenParsec — 个人自用 iOS 串流客户端

基于 [OpenParsec](https://github.com/PowehiZ/OpenParsec-Personal-IPA) 的个人修改版：在保留 Parsec 串流核心能力的基础上，重点重做了**手柄 / 陀螺仪输入**与**设置界面**。

> 本仓库由 GitHub Actions 自动编译成未签名 IPA，产物在 [Releases → nightly](https://github.com/PowehiZ/OpenParsec-Personal-IPA/releases/tag/nightly)。

---

## 一、功能总览

### 1. 连接与串流

| 功能 | 说明 |
|---|---|
| 账号登录 | Parsec 账号密码 / 已签发 session 复用 |
| 主机列表 | 拉取自己的在线主机，点选即连 |
| 自动重连 | 断线后自动尝试重连 |
| 错误提示 | 连接失败时弹窗显示原因 |
| 后台保活 | 切到后台/锁屏时暂停视频、恢复音频，回到前台自动恢复 |
| 状态覆盖层 | 可随时查看码率、延迟、丢帧；可设为永不显示 |

### 2. 画面

| 设置 | 可选值 |
|---|---|
| 分辨率 | Host / Client / 3840×2160 / 2560×1600 / 2560×1440 / 2560×1080 / 1920×1200 / 1920×1080 / 1600×900 / 1280×800 / 1280×720 等（16:9、16:10、21:9） |
| 帧率 | 30 / 60 / 120 / 跟随设备（ProMotion） |
| 解码器 | H.264 / H.265（HEVC） |
| 解码器兼容模式 | 解决部分机型的解码卡顿 |
| 画中画 | 支持 PiP 悬浮窗 |
| 隐藏状态栏 | 全屏沉浸 |
| 键盘按钮 | 屏幕上的虚拟键盘入口开关 |
| 静音启动 | 进入串流默认静音 |

### 3. 触控 / 鼠标输入

| 设置 | 行为 |
|---|---|
| 鼠标移动模式 | **触控板**（相对移动）/ **直触**（绝对定位） |
| 右键位置 | 第一根手指 / 中间 / 第二根手指 |
| 滚轮速度 | 0.5× – 5× |
| 反向滚动 | 滚轮方向取反 |
| 光标缩放 | 0.1× – 4× |
| 鼠标灵敏度 | 0.1× – 4× |
| 选项键作为 Command | 虚拟键盘的 Option 映射为 ⌘ |
| USB / 蓝牙鼠标 | 支持实体鼠标按键、移动与滚轮 |

### 4. 手柄

| 功能 | 说明 |
|---|---|
| 全键重映射 | 16 个物理键（A/B/X/Y、LB/RB、LT/RT、L3/R3、START/BACK、十字键四向）各自可映射到 21 种目标：任意按钮、LX/LY/RX/RY、LT/RT，或**禁用** |
| 映射存储 | JSON 存 UserDefaults，改完立即生效并持久化，可一键恢复默认 |
| 死区 | 0 – 0.5，超出部分重新线性映射，避免跳变 |
| Y 轴反转 | 左右摇杆独立反转 |
| 交换 A/B 与 X/Y | 只影响默认映射，手动改过的键以映射表为准 |
| 第二只手柄 | 最多同时绑定 2 只（Parsec 协议支持 4 个控制器 ID） |
| 震动反馈 | 接收主机的 `CLIENT_EVENT_RUMBLE`，通过 CoreHaptics 驱动手柄马达：大马达控制强度、小马达控制锐度，用常驻连续事件 + 动态参数调节，无咔哒声 |
| 按键测试 | 实时显示「物理键 → 实际发出的键 #controllerID」 |
| 震动测试 | 直接驱动一次 1.0 强度震动，并在旁显示**最近收到的主机震动强度百分比**（用于区分「主机没下发」和「手柄不支持」） |
| 状态 / 电量 | 显示手柄型号、数量与电量 |

### 5. 陀螺仪体感

> Parsec 协议**没有陀螺仪通道**，因此体感只能通过模拟鼠标位移或右摇杆轴实现。

| 功能 | 说明 |
|---|---|
| 输出目标 | **模拟鼠标**（100Hz 位移，亚像素余量累积）或 **模拟右摇杆**（与你推的摇杆叠加后统一发出） |
| 水平 / 垂直灵敏度 | 0.2× – 4× |
| 死区 | 0 – 0.15 rad/s |
| 平滑 | 0 – 0.9 低通滤波系数 |
| 水平 / 垂直反转 | 独立反转 |
| L2 激活闸门 | 可要求「按住 L2 才输出体感」；未接手柄时自动放行 |
| 手柄自带陀螺仪 | iOS 17+ 优先使用手柄 IMU（DualSense / DS4）；用重力模长判断手柄是否真的带传感器，没有则自动回退手机陀螺仪 |
| 归中 | 重新做零偏校准（0.5 秒静止采样） |
| 实时状态 | 状态行显示 运行中 / 样本数 / 角速度 / 闸门状态，并配一条 0–180 °/s 的实时强度条 |
| 看门狗 | 1.5 秒收不到样本直接提示「没收到陀螺仪数据」 |

### 6. 界面

- **卡片式设置页**：分组卡片、每行配图标、顶部信息卡显示版本指纹（版本号 · build 数 · commit）与手柄/陀螺仪实时状态胶囊。
- **图形化选项**：关键设置不再是纯文字，选项本身就是示意图，**点卡片直接选中**：
  - 数值类（光标缩放、滚轮速度、鼠标灵敏度、摇杆死区、陀螺仪灵敏度/死区/平滑）：一行内的小卡，卡内缩略图随档位变化；
  - 开关类中「开/关会改变画面」的 4 项（隐藏状态栏、键盘按钮、画中画、陀螺仪启用）保留两张图形卡，其余开关回到紧凑单行开关以节省空间；
  - 多选类（鼠标移动、右键位置、陀螺仪输出）：扁平方形胶囊。
- **语言切换**：设置页顶部「通用 → 语言」，可在 English / 中文 间切换并立即生效。
- **深浅色**：跟随系统。

## 二、构建：推送即出 IPA

```
推送到 main
   ↓
GitHub Actions（macos-latest）
   ├─ 拉取 ParsecSDK 6.0（commit bb33669）
   ├─ xcodebuild archive，CODE_SIGNING_ALLOWED=NO
   ├─ 打包 Payload，Ubuntu 上用 ldid 假签名
   └─ gh release upload → nightly（覆盖 OpenParsec.ipa）
```

- 构建号取 Actions 的 run number，已写入 `CFBundleVersion`，装完在设置页顶部能看到，用来确认装的是哪一次构建。
- 产物地址固定：
  `https://github.com/PowehiZ/OpenParsec-Personal-IPA/releases/download/nightly/OpenParsec.ipa`

### 安装方式

IPA **未签名**（用 ldid 假签名），不能直接双击安装：

| 方式 | 说明 |
|---|---|
| AltStore / SideStore | 用 Apple ID 自签，7 天需续签 |
| TrollStore | 需对应系统版本，装完永久有效 |
| Sideloadly / Xcode | 用开发者证书签名后安装 |
| 付费企业证书 | 自行处理 |

## 三、已知限制

1. **震动依赖主机下发**：只有主机侧把 rumble 提交给客户端（如官方 Windows host 对接 XInput）才会收到数据。手柄插在客户端、主机没有对应虚拟手柄时，一条数据都不会有 —— 此时设置页的震动强度会一直是 0%。
2. **部分手柄不暴露震动能力**：第三方手柄（例如 GameSir G8+ 某些模式）可能让 iOS 认为它不支持 CoreHaptics，震动测试会直接提示「该手柄不支持震动」。
3. **陀螺仪是模拟输入**：协议层没有原生体感，鼠标/右摇杆模拟在少数游戏里手感不完美。
4. **不支持手柄陀螺仪的老系统**：iOS 17 以下只能用手机陀螺仪。
5. **无可用测试机**：本项目在 Windows 上开发，靠 CI 编译与真机反馈迭代，个别机型的解码/渲染问题可能需要继续调。

## 四、目录结构

```
.github/workflows/build.yml   CI：编译 + 假签名 + 发布
OpenParsec/
  CParsec.swift               对外门面（可选实例 + NSLock，避免未连接时崩溃）
  ParsecSDKBridge.swift       SDK 桥接：连接、视频/音频/事件轮询、鼠标、震动事件
  GameController.swift        手柄 + 陀螺仪：映射表、分发、震动引擎、体感采样
  SettingsView.swift          设置页（33 个图形选项 + 分组卡片）
  ExUI.swift                  界面组件：卡片、徽章、仪表条、图形选项、示意图
  SettingsHandler.swift       所有 @AppStorage 设置项
  Shared.swift                中英文本地化
  ParsecViewController.swift  触控/手势、渲染视图几何
  ...
Frameworks/                   ParsecSDK.framework（CI 拉取，不入库）
```

## 六、本版变更（相对上游）

- 手柄：新增 **16 键全键重映射**（21 种目标）、**主机震动通道**（`CLIENT_EVENT_RUMBLE` → CoreHaptics，含强度/锐度映射与引擎复用）、按键测试、震动测试与强度指示。
- 陀螺仪：新增体感（鼠标 / 右摇杆双模式）、灵敏度/死区/平滑/反转、L2 闸门、零偏校准、手柄 IMU 优先与自动回退、实时状态条与看门狗。
- 设置页：全量重做为卡片式；33 个设置改为**图形化可点选选项**；顶栏加入版本指纹与实时状态胶囊；新增中英切换。
- 稳定性：`CParsec` 全静态方法改为「可选实例 + 锁」，未连接或已断开时不再向失效 client 发消息；所有 ParsecSDK 调用统一回主线程；去除全部强制解包。
